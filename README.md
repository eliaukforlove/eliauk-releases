# Eliauk

角色陪伴，属于你们的日常。

[下载安装包](https://github.com/eliaukforlove/eliauk-releases/releases/latest)

支持 Android 9 及以上的 arm64 设备。安装后自行配置模型服务；手机操作需要额外的系统授权。

后续可在应用「设置 → 应用更新」检查并下载安装新版本。覆盖安装会保留聊天、角色、资料和设置，请勿先卸载。

部分 OPPO / ColorOS 手机从 Chrome 下载或直接打开安装包时，会提示“没有签名文件”。可以先尝试从「文件管理 → 下载」打开；若仍失败，可通过微信传输 APK 后从文件管理器安装，这是已在 OPPO Reno14 上验证成功的路径。也可尝试应用内更新，应用会先校验安装包完整性和签名。

目前为早期测试版，不同手机的后台运行、授权和触感体验仍在完善。此仓库只提供安装包与更新说明，不包含应用源码。第三方许可证随安装包保留。
